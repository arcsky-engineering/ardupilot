# Xplorer parameter manifest - the authoritative row set for the generated docs.
#
# WHY THIS FILE EXISTS
#   A parameter only appears in a GCS param download if its feature is enabled
#   (e.g. RNGFND3_TYPE=0 collapses the whole RNGFND3_ subgroup, BATT4_MONITOR=0
#   collapses BATT4_). That cannot be determined from source alone, so the row
#   set comes from a real param download off a configured airframe, plus any
#   params added to the firmware since.
#
# HOW TO UPDATE
#   1. Full param download from a configured Xplorer (Mission Planner / QGC),
#      save as .parm, then:  python Tools/xplorer/sync_manifest.py <file>.parm
#   2. Or add a name by hand when you add a param to the firmware.
#   3. Update baseline-commit below to HEAD once the manifest matches the source.
#
# baseline-commit is the last commit whose new parameters are known to be listed
# here. gen_param_docs.py diffs baseline..HEAD for added AP_GROUPINFO/GSCALAR
# definitions and FAILS if any are missing from this file - that is the check
# that would have caught BATT*_LOW_SOC/CRT_SOC/ARM_SOC sitting undocumented.
#
# baseline-commit: cc3aec9c4f
# provenance: live param download + BATT SOC failsafe params (5fab6c5e26)
# count: 1232
