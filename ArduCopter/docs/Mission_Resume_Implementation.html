Mission Resume After Power Cycle

Implementation Guide for ArduPilot

Feature Summary: This feature allows ArduPilot to save mission progress to non-volatile memory (NVM) and automatically resume from the last waypoint after a power cycle, eliminating the need to manually restart missions or reconfigure via ground control station.

1. Overview

What Problem Does This Solve?

Previously, if you powered off your flight controller mid-mission, the mission progress was lost. Upon reboot, you had to either:

  • Restart the mission from the beginning
  • Manually select a waypoint in your ground control station
  • Hope that QGroundControl remembered your position (which didn't always work)

Now: The system automatically saves your mission progress when you exit AUTO mode or disarm, and resumes from that exact position when you enter AUTO mode again, even after a complete power cycle.

Two-Tier Recovery System

Scenario Recovery Mechanism Storage Location Survives Power Cycle?
Software Crash / Watchdog Reset Existing persistent_data.waypoint_num Special RAM region ❌ No (RAM cleared on power cycle)
Power Cycle Between Flights New MIS_LAST_INDEX parameter EEPROM/Flash (NVM) ✅ Yes

2. How It Works

Mission Resume Flow

Start Mission in AUTO Mode
↓
Fly Waypoints 1 → 2 → 3 → 4
↓
Exit AUTO Mode or Disarm
MIS_LAST_INDEX = 4 saved to Flash
↓
Power Off Flight Controller
↓
Power On Flight Controller
↓
Enter AUTO Mode
Check MIS_RESTART parameter
↓
Resume from Waypoint 4
GCS Message: "Mission: Resuming from saved index 4"

When Mission Index is Saved

The system saves your current waypoint index to NVM in two situations:

  1. Exiting AUTO Mode - When you switch from AUTO to any other flight mode (e.g., LOITER, RTL, LAND)
    • Triggered in AP_Mission::stop()
    • GCS Message: "Mission: Saved index X for resume"
  2. Disarming - When you disarm the vehicle
    • Triggered in AP_Mission::check_and_save_on_disarm()
    • GCS Message: "Mission: Saved index X for resume"

When Mission Index is Cleared

The saved index is automatically reset to 0 when:

  • Mission Completes Successfully
    • All waypoints executed
    • GCS Message: "Mission: Complete, cleared saved index"
    • Ensures next flight starts from the beginning

3. Configuration

Required Parameter Settings

Parameter Value Description
MIS_RESTART 0 (Resume Mission) Controls whether to resume or restart mission when entering AUTO mode. Must be 0 to use saved index.
MIS_LAST_INDEX Auto-managed Last waypoint index, automatically saved/cleared by system. Read-only, do not manually edit.
⚠ Important: If MIS_RESTART=1 (Restart Mission), the saved index will be ignored and the mission will always restart from waypoint 1.

Setting Parameters via Mission Planner

  1. Connect to your flight controller
  2. Go to CONFIG → Full Parameter List
  3. Find MIS_RESTART and set it to 0
  4. Click Write Params
Note: MIS_LAST_INDEX has the INTERNAL_USE_ONLY flag, so it won't appear in the normal parameter list in Mission Planner. You can view it in the full parameter file if you save parameters to a file.

4. Testing Procedures

Test 1: Basic Resume After Power Cycle

Objective: Verify mission resumes from correct waypoint after power cycle
  1. Setup:
    • Create a simple mission with 5-7 waypoints
    • Set MIS_RESTART=0
    • Upload mission to flight controller
  2. Execute:
    • Arm and take off
    • Enter AUTO mode
    • Fly through waypoints 1, 2, 3
    • Switch to LOITER or another mode
    • Watch for GCS message: "Mission: Saved index 3 for resume"
    • Land and disarm
    • Power off the flight controller completely
    • Wait 10 seconds
    • Power on the flight controller
  3. Verify:
    • Arm and take off
    • Enter AUTO mode
    • Watch for GCS message: "Mission: Resuming from saved index 3"
    • Verify vehicle proceeds to waypoint 4 (not waypoint 1)

Test 2: Mission Complete Clears Saved Index

Objective: Verify saved index is cleared after mission completes
  1. Execute:
    • Start mission in AUTO mode
    • Let mission run to completion (all waypoints)
    • Watch for GCS message: "Mission: Complete, cleared saved index"
    • Power cycle the flight controller
  2. Verify:
    • Enter AUTO mode again
    • Mission should start from waypoint 1 (not resume from end)

Test 3: Resume After Disarm (No Mode Change)

Objective: Verify index saved when disarming while still in AUTO mode
  1. Execute:
    • Start mission, fly through several waypoints
    • Land while still in AUTO mode
    • Disarm (without switching modes)
    • Watch for GCS message: "Mission: Saved index X for resume"
    • Power cycle
  2. Verify:
    • Mission resumes from saved waypoint

Test 4: MIS_RESTART Override

Objective: Verify MIS_RESTART=1 always restarts mission
  1. Setup:
    • Fly partway through mission
    • Exit AUTO, verify index saved
    • Set MIS_RESTART=1
  2. Verify:
    • Enter AUTO mode
    • Mission should start from waypoint 1 (saved index ignored)

5. GCS Messages Reference

Message When It Appears Meaning
Mission: Saved index X for resume Exiting AUTO mode or disarming Mission progress saved to NVM, will resume from waypoint X after power cycle
Mission: Cleared saved index (no active waypoint) Disarming with no active mission No waypoint to save, cleared saved index
Mission: Complete, cleared saved index Mission completes successfully All waypoints executed, ready for fresh start next time
Mission: Resuming from saved index X Entering AUTO mode with saved index Restoring mission from waypoint X (from NVM)

6. Technical Implementation Details

Files Modified

  • libraries/AP_Mission/AP_Mission.h - Added parameter and method declarations
  • libraries/AP_Mission/AP_Mission.cpp - Implemented save/clear/resume logic

Key Code Locations

Function Purpose File
AP_Mission::stop() Saves index when exiting AUTO mode AP_Mission.cpp
AP_Mission::check_and_save_on_disarm() Detects disarm and saves index AP_Mission.cpp
AP_Mission::complete() Clears saved index on mission complete AP_Mission.cpp
AP_Mission::resume() Restores from saved index on mission start AP_Mission.cpp

Parameter Storage

Parameter Name: MIS_LAST_INDEX
Type:           AP_Int16 (16-bit integer)
Storage:        EEPROM/Flash (NVM)
Default:        0 (no saved position)
Flags:          INTERNAL_USE_ONLY, ReadOnly
Index:          3 (in AP_Mission parameter group)

7. Troubleshooting

Problem: Mission Always Restarts from Beginning

Solutions:

  • Check MIS_RESTART parameter - must be 0 (Resume Mission)
  • Verify you're seeing the "Mission: Saved index X" message when exiting AUTO or disarming
  • Ensure mission didn't complete (which clears the saved index)

Problem: Not Seeing GCS Messages

Solutions:

  • Check GCS message console/log window
  • Verify GCS is connected and receiving telemetry
  • Check message severity filter (messages are MAV_SEVERITY_INFO level)

Problem: Resumes from Wrong Waypoint

Solutions:

  • Check what waypoint was active when you exited AUTO mode
  • Note: System saves the current navigation waypoint, not the next one
  • If you modified the mission after saving, the index might be invalid

Problem: "Cleared saved index (no active waypoint)" Message

This is normal if:

  • You disarmed before starting a mission
  • Mission was already complete
  • No navigation command was loaded

8. Limitations & Considerations

Important Limitations

  • Mission Must Be Unchanged: If you upload a different mission after saving the index, the saved index may point to an incorrect or non-existent waypoint
  • Only Works with MIS_RESTART=0: Resume functionality requires MIS_RESTART set to 0 (Resume Mission mode)
  • Index Only, Not Position: System saves waypoint index, not GPS position. Vehicle will navigate to the saved waypoint from current position
  • Flash Write Frequency: Index is written to flash only when exiting AUTO or disarming, not during flight (to minimize flash wear)

9. Best Practices

  • Always Monitor GCS Messages: Pay attention to save/resume messages to understand system behavior
  • Test Before Critical Missions: Verify resume functionality works with your specific mission profile
  • Don't Edit Missions Between Flights: If you save a position at waypoint 5, don't upload a new mission with only 3 waypoints before resuming
  • Complete Missions When Possible: Letting missions complete naturally clears the saved index, preventing confusion on next flight
  • Keep MIS_RESTART=0: Once you enable resume functionality, keep MIS_RESTART at 0 unless you specifically want to restart missions

10. Future Enhancements

Possible future improvements to this feature:

  • Save/restore DO command state
  • Option to save GPS position along with index
  • Mission change detection (warn if mission modified since save)
  • Multiple saved mission positions (slots)
  • Parameter to control auto-clear behavior
